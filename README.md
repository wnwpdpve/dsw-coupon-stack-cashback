## DSW lets you stack up to 3 promo codes — here's how people get it wrong

This is the detail most coupon roundups mention in passing and then never explain. DSW allows **up to three promo codes on a single order**, both online and in stores. So a realistic order might combine a percentage-off code, a shipping code like FREESHIP, and a category code — as long as none of them conflict.

When a code gets rejected, it's almost always one of these four reasons:

1. **Brand exclusions.** Most codes exclude a list of brands (typically newer, premium, or already-discounted labels). The exclusions are in the offer's fine print on DSW's site.
2. **Minimum spend not met.** The threshold is calculated on the price after other discounts, before shipping.
3. **New-customer codes already used.** These are one-time codes tied to the email that received them — you have to check out with that same account.
4. **Channel mismatch.** Some codes are store-only or online-only, and the checkout won't warn you beforehand.

There's a fifth failure mode that almost nobody writes about, and it costs real money if you care about cashback: **using a coupon code that didn't come from the cashback portal's own page can void your cashback entirely.** TopCashback's DSW page says this explicitly. The workaround is simple — click through to DSW from the portal first, then only use codes listed on that same portal page, and your 2% survives.
